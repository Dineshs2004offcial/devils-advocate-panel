# Requirements

## Software

- Python 3.x
- Node.js
- npm
- PostgreSQL
- Git

## Backend

Install:

```text
backend/requirements.txt
```

## Frontend

Install dependencies with:

```bash
cd frontend
npm install
```

## Configuration

Environment variables may include AI/LLM credentials, PostgreSQL configuration, application URLs and external tool settings.

Use `.env.example` for the actual variable names.
